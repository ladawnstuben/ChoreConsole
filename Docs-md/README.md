# Docs-md persistence system

This directory is the durable handoff state for Claude Code sessions.

Core files:
- PROGRESS.md: current state and what has been completed
- NEXT_STEPS.md: ordered unfinished work
- DECISIONS.md: durable decisions and rationale
- WORK_LOG.md: concise chronological work record
- Claude-Memory/: Claude Code auto-memory stored inside this project
